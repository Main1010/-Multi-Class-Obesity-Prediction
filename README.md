This repository contains the official implementation of our IEEE QPAIN 2026 paper:

# Title: Explainable AI for Multi-Class Obesity Prediction Using Machine Learning Models

The framework applies data preprocessing, feature scaling, SMOTE, and class-weighted learning to handle data imbalance, followed by six machine learning models (Logistic Regression, Random Forest, XGBoost, LightGBM, CatBoost, and SVM) for multi-class obesity classification. Hyperparameter optimization is performed using GridSearchCV, while Explainable AI using SHAP is incorporated to interpret model predictions and identify the most influential features contributing to obesity classification.

Dataset Link: https://archive.ics.uci.edu/dataset/544/estimation+of+obesity+levels+based+on+eating+habits+and+physical+condition
